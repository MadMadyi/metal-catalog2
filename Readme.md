# Metal Catalog

Справочник и система автоматизации обработки металлопроката.

## Цель проекта

Проект предназначен для ускорения работы с таблицами металлопроката.

В будущем программа должна уметь:

- определять тип металлопроката по наименованию;
- распознавать размеры;
- определять подходящий ГОСТ;
- находить соответствующую позицию в справочнике;
- присваивать ID материала;
- формировать полное наименование;
- определять массу погонного метра;
- рассчитывать общий метраж;
- рассчитывать тоннаж;
- находить одинаковые позиции;
- отмечать неоднозначные или сомнительные совпадения.

## Поддерживаемые типы металлопроката

Планируется поддержка:

- арматуры;
- двутавров;
- швеллеров;
- уголков;
- листового металла;
- труб;
- кругов;
- полос;
- шестигранников;
- профнастила;
- арматурных сеток;
- других видов металлопроката.

## Пример

Исходные данные:

Швеллер 14П, 12 м, 10 шт.

Результат обработки:

- Тип: швеллер
- Размер: 14П
- ГОСТ: определяется автоматически
- Количество: 10 шт.
- Длина одной позиции: 12 м
- Общий метраж: 120 м
- Масса 1 м: определяется по справочнику
- Общий вес: рассчитывается автоматически
- ID: определяется по справочнику

## План разработки

### Этап 1
Создание структуры проекта.

### Этап 2
Распознавание наименований и размеров металлопроката.

### Этап 3
Справочник ГОСТ.

### Этап 4
Справочник массы металлопроката.

### Этап 5
Автоматическое сопоставление с внутренним справочником ID.

### Этап 6
Обработка Excel-файлов.

### Этап 7
Автоматическое заполнение:

- ГОСТ;
- ID;
- полного наименования;
- массы погонного метра;
- общего метража;
- тоннажа;
- примечаний.

### Этап 8
Проверка ошибок и неоднозначных совпадений.
